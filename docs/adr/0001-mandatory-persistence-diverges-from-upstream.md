# Mandatory persistence of inbound emails, no opt-out

The upstream package this was forked from is entirely stateless: it verifies a webhook, builds an `InboundMessage` DTO, and dispatches the consuming app's own queued job — no database dependency, no config toggle needed because there was nothing to toggle. This fork's purpose is to durably log every inbound email as an `InboundEmail` Eloquent record, so persistence is always on rather than behind a config flag. We considered making it opt-in to avoid forcing a new `illuminate/database` dependency and migration onto existing consumers, but rejected that: a package whose entire reason for existing is "logged inbound email" that silently does nothing unless configured would be confusing, and consumers who don't want this behavior can stay on the unforked upstream package instead.
